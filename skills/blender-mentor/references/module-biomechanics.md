## 1. 适用场景

**适用**
- 任何需要"重量/发力/受击"可信度的人体或类人生物动作；
- 角色绑定、蒙皮、肌肉形变、动作评审。

**不适用**
- 机械、纯风格化橡皮管、非解剖角色（需显式声明"非写实"并单独定标准）。

**判定问题**
1. 这个动作的支撑脚/支撑面在哪里？
2. 力从哪来、经过哪些关节、最后到哪里？
3. 离心/向心/等长三段分别在哪几帧？
4. 质心（CoM）轨迹是否随支撑变化？

## 2. 动力链与重心

### 2.1 鞭打式动力链

```text
脚底 GRF → 踝跖屈/背屈 → 膝伸/屈 → 髋伸/屈 → 骨盆旋转/倾斜
        → 腰椎 → 胸椎 → 肩胛/锁骨 → 上臂 → 前臂 → 手
```

- **近端先动、远端滞后**（proximal-to-distal）：骨盆/躯干先建立支点与角动量，末端最后加速；
- 例外：distal-to-proximal / 同步发力也真实存在（投掷末段、精细操作）；默认按 proximal-to-distal 分析，但动作分析要给出依据。
- 不允许"局部孤立发力"：手臂摆动不能只转肩，膝击不能只转大腿；
- 支撑期先有 GRF 再谈姿势；腾空期无 GRF，只能靠初速度与角动量。

### 2.2 重心（CoM）与支撑面

- 支撑期：CoM 投影必须落在支撑面内（双支撑/单支撑）；
- 落地缓冲：Hips 世界 Z 必须有可测下沉（**要求 ≥2 cm**，默认；非人体/风格化按 rubric §6 #9 N/A）与回弹，不允许水平直线；
- 腾空期：CoM 轨迹近似抛物线，水平速度近似恒定（忽略空气阻力）；
- 受击：力必须传到全身——重心后移、膝屈、脚滑动/后撤，不能"脚钉死、只用脊柱折"。

### 2.3 起跳/落地时间基准

- 跳高 `h` 的自由飞行时间：`T = 2·√(2h/g)`；
- 24 fps 下，0.50 m 跳高 `T ≈ 0.639 s ≈ 15 帧`；
- 验收：实测腾空帧数与理论值误差 ≤1 帧；否则判定"低重力/漂浮"。

## 3. 肌肉收缩 ↔ Graph Editor 映射（强制）

| 收缩类型 | 动作含义 | 曲线/手柄 | 验收 |
|---|---|---|---|
| **向心**（缩短、加速发力） | 蹬伸、挥击、起跳 | 慢出快进：Ease In 弱、Ease Out 强；末端斜率增大 | 末段斜率单调增，峰值前不提前减速 |
| **离心**（拉长、制动退让） | 下蹲、落地缓冲、受击后退 | 快出慢进：Ease In 强；末端 2–3 帧斜率递减但不归零 | 末端 3 帧斜率单调递减且 `abs(slope) > 0` |
| **等长**（支撑稳定） | 接触 hold、支撑相 | **Linear / Constant**，禁止 Bezier 漂移 | hold 段数值平台，偏移 ≤0.05 mm/帧 |

> 关键：曲线形状是肌肉行为的**结果**，不是"手调好看"。先定收缩类型，再选插值。

## 4. 体积保持与肌肉形变

### 4.1 为什么只旋转骨骼会"像纸片"

- 骨段旋转保持段内体积，但**关节区域没有体积补偿**：肘内侧被压扁/自交，外侧被拉长；
- 单骨旋转不改变肌肉横截面，肱二头肌/肱三头肌不会鼓起；
- 线性蒙皮在关节处产生"折纸"式塌陷，角度越大越明显。

### 4.2 解决管线（Picaut 工作流）

1. 底层：Armature 修改器开启 `use_deform_preserve_volume`（双四元数）；
2. 关节层：Corrective Smooth / 关节补面；
3. 肌肉层：Shape Key（形态键）：
   - `BicepsBulge`（屈肘时肱二头肌膨胀）；
   - `TricepsBulge`（伸肘/离心时肱三头肌绷紧）；
   - `ElbowFill`（肘窝填充，防塌陷）；
4. **全部由驱动器自动驱动**，禁止手动 K 形态键；
5. 验收：0°/45°/90°/120° 四角度体积、围度、无自交。

### 4.3 驱动器写法（骨骼版）

Driver：
- Variable `rot`：`Transform` → target `Rig` → bone `forearm.L` → `Rotation X` → `Local Space`
- Expression：
  - `BicepsBulge`：`min(1.0, abs(rot) / 1.5708)`
  - `TricepsBulge`：`min(1.0, max(0.0, -rot) / 1.5708)`
  - `ElbowFill`：`min(1.0, abs(rot) / 2.0)`

Empty 版：
- Empty 加 `Copy Rotation`（target `forearm.L`，Local/Local，Replace）；
- Driver 读 Empty 的 `Rotation X`，表达式同上。

## 5. Rubric §4.7 子维度：生物力学合理性

| 分 | 标准 |
|---|---|
| 0 | 关节乱转、无发力意识、反关节、肌肉像塑料 |
| 1 | 有关节运动，但缺发力链条，CoM 不随支撑脚转移 |
| 2 | 发力链条基本正确，缓冲段有离心张力，CoM 轨迹符合物理 |
| 3 | 动力链清晰，肌肉有明确向心/离心切换，体积保持完美（无塌陷），有"重量 settle 到髋部"的细节 |

**权重**：§4.7 内 25%；**关键项**：人体/类人动画必须 ≥2（见 rubric §6 第 9 项）。
**N/A 规则**：非人体/纯风格化项目需在自评中显式声明，不得默认满分。

## 7. 常见 P0 错误（真实复盘）

| 编号 | 错误 | 证据 | 修正 |
|---|---|---|---|
| BIO-P0-1 | 无蹬地相、滞空低重力 | 腾空时间与跳高不符；脚提前离地 | 脚锁地 3–5 帧 → 髋膝踝伸展 → 离地；按 `2√(2h/g)` 重排 |
| BIO-P0-2 | 动力链断裂、局部发力 | 近端环节不参与，末端各自摆姿势 | 先排骨盆/脊椎时序，末端滞后；手臂作为配重 |
| BIO-P0-3 | 受击无重心转移、反关节 | 支撑脚完全钉死、髋部几乎不后移、颈椎超出生理范围 | 重心后移 + 膝屈 + 撤步/滑步；颈椎限制 ~50–60°，余量给胸椎 |

## 8. 15 分钟发力感练习

| 时间 | 任务 | 自检 |
|---|---|---|
| 0–3 min | 看参考，标 contact / toe-off / apex / land | 四帧对应脚底、髋、肩时序 |
| 3–8 min | 5 个 pose：站立、离心最低、蹬伸、腾空膝击、落地缓冲 | 蹬伸前脚不离地；Hips Z 先降后升 |
| 8–12 min | 落地段 3 帧离心，Graph Editor 查斜率 | 末端 3 帧斜率递减、不归零 |
| 12–15 min | 屈肘 90° + 肱二头肌 Driver | 无手 K Shape Key；肘窝不塌 |

**及格线**：滞空误差 ≤1 帧；脚底 ≥−1 mm；Hips Z 下沉 >2 cm；形态键 0 手 K 关键帧。
