## 4. 模块前测 / 后测（样例）

### 4.1 M0 前测（10 分）
1. 1 BU 默认等于多少米？（1）
2. 缩放未 Apply 会导致什么问题？举两个。（2）
3. 非流形边的定义是什么？（1）
4. 颜色贴图应使用什么色彩空间？（1）
5. AgX 与 Standard 的区别？（2）
6. 1080p/30fps 的 H.264 应如何设置？（2）
7. 如何检查贴图丢失？（1）

**答案**：1）1m；2）修改器/物理/导出异常；3）被两个以上面共享或开放边；4）sRGB；5）AgX 高光滚降更自然、Standard 直出；6）`media_type=VIDEO`、MPEG4/H.264、30fps、1920×1080；7）Find Missing Files / 检查相对路径。

### 4.2 M3 后测（基础 10 + 加分 2）
1. 30fps 下接触挤压至少 hold 几帧？（1）
2. 抛物线关键帧手柄如何设置才能匹配重力？（2）
3. squash & stretch 的预拉伸与回弹各占几帧（30fps 基线）？（2）
4. 为什么滚动轴是 Y 而不是 Z？（2）
5. 如何验证循环动画无缝？（1）
6. 约束顺序错误会导致什么？（1）
7. 如何用 60fps 验收接触节奏？（1）
8. **加分题（2）**：冲击速度从 6.26 m/s 降到 0.78 m/s，形变应该怎么变？写出缩放公式，并说明为什么不能只缩 squash。

**答案**：1）2 帧；2）按段长 Δ 设置 handle `(t0+Δ/3, z0+v0Δ/3)` 与 `(t1−Δ/3, z1−v1Δ/3)`；3）预拉伸 2 帧、挤压 hold 2 帧、回弹 3 帧 + 过冲；4）`v=ω×r`，X 前进时 ω 必须绕 Y 才能在触地点产生向前滚动，Z 是陀螺自转；5）首尾值+切线一致（Cycle Modifier 检查）；6）结果与预期相反/动画失效；7）按 2 倍帧重定时渲染接触窗口逐帧对照；8）`A_i = A_0·(v_i/v_0)^p`（p≈0.8）；pre-stretch/recover/overshoot/hold/tilt/window 全部按同一 k 缩放，并设 cutoff 与非重叠约束——只缩 squash 会让尾部"用大球模板演小球"，出现抖动与顶点形变。

**通过线**：基础分（Q1–Q7，满分 10）≥7/10；Q8 加分只用于优秀档（基础+加分 ≥10），不计入通过。

### 4.3 M3-W13 行走循环交付清单（自评 + 修改清单，V5.2.0）

> 交付必须按主文档 `§2.8` 走完 D1→D4；评分引用 `rubric §11`。以下任一缺失按交付不完整处理。

```text
[ ] 30fps 循环长 / 2 步 / 8 姿势帧写清楚；frame_end 与循环长一致
[ ] 循环：首尾姿势一致（全骨骼矩阵）+ 首尾切线连续；所有曲线带 Cycles
[ ] 接触硬门槛（机器/必过）：支撑期脚底穿地量 min z ≥ −1mm；支撑速度恒定（原地 -v / 世界空间踩住）
[ ] 接触质量（评分目标）：支撑帧脚底绝对误差 |z| ≤0.1mm（与硬门槛分开记）
[ ] 脚部：heel→ball→toe 分阶段（有 toe 骨/脚趾角度曲线），toe 在 heel-rise 期贴地
[ ] 亚帧（60fps 交付时）：半帧/1/8 帧采样脚底穿地 ≤0.05mm
[ ] 膝盖：始终朝前（矢状面），侧偏 ≤10mm；IK 末端误差 ≤0.5mm
[ ] 手臂：与对侧腿反相（相关 ≤−0.8），摆幅有意图
[ ] 躯干/头：有反向扭转与滞后（不能完全抵消、不能 1:1 跟随）
[ ] 左右不完美对称（1–5% 差异），有意图
[ ] **生物力学（BIO-001）**：脚底 GRF → 踝/膝/髋/骨盆/脊椎/肩带时序可解释；近端先动、远端滞后
[ ] **起跳/落地**：跳高 h 的腾空时间 = 2√(2h/g)（误差 ≤1 帧）；支撑期脚底穿地 ≥−1mm；落地 Hips Z 下沉 ≥2cm
[ ] **肌肉体积**：屈肘/屈膝极限角度无关节塌陷；肌肉 Shape Key 全部 Driver 驱动，Action 中 0 手 K 关键帧
[ ] 视频规格：1920×1080 / 30fps / 循环帧数 / H.264；验收从 movieclip 反查
[ ] 自评表 + 修改清单 + 明确询问（主文档 §2.8 D4）
```

### 4.4 M3 生物力学后测（10 分，V5.3.0 / BIO-001）

| 题 | 分值 | 评分点 |
|---|---|---|
| 给一段"站立→起跳→落地"，标出 contact / toe-off / apex / land 四帧 | 2 | 四帧与脚底/髋/肩时序对应 |
| 写出该动作的动力链（脚→踝→膝→髋→骨盆→脊椎→肩带）并指出近端/远端 | 2 | 无孤立发力 |
| 计算 0.35 m 跳高的理论滞空帧数（24fps） | 2 | `T=2√(2h/g)`，结果 ≈0.534 s ≈13 帧 |
| 解释向心/离心/等长分别对应什么手柄与断言 | 2 | 向心慢出快进；离心快出慢进且末端不归零；等长 Linear/Constant |
| 写出一个肘部肌肉 Shape Key 的 Driver 表达式（90° 为 1） | 2 | 变量/空间正确，无手 K 关键帧 |

**通过线**：≥7/10；第 3/5 题任一 0 分 = M3 生物力学未通过。

> 本节（§4.4 生物力学专项）与 §4.2 综合后测是不同测试，通过线各自计算（§4.2 看基础 7/10；本节看 7/10）。

## 5. Capstone 选题（三轨，任选一）

### A. 资产轨（Modeler/Game）
交付：1 个干净资产（角色/道具/环境件）+ UV + PBR 材质 + 3 视角渲染 + 拓扑/面数报告。
验收：评分表 ≥2.0、关键项 ≥2；能解释每个建模决策。

### B. 动画轨（Animator/Rigger）
交付：5–10 秒镜头（角色/物体动画均可）+ 曲线截图 + timing 说明 + 60fps 关键段。
验收：曲线可读、无穿帮、循环/接触正确、能解释节奏依据。

### C. 管线轨（TD）
交付：1 个可复用工具（bpy 或 GN）+ 资产门/日志 + 1 次性能优化前后数据 + 使用文档。
验收：幂等、有日志、不污染场景、性能提升可量化。
