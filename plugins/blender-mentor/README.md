# Blender Mentor - Claude Code plugin

This plugin packages the `blender-mentor` Agent Skill.

## Install

```text
/plugin marketplace add Memory175/blender-mentor
/plugin install blender-mentor@blender-mentor-marketplace
```

The skill lives at `skills/blender-mentor/SKILL.md`; its `references/`, `scripts/` and `assets/` are bundled next to it.
