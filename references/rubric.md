# Blender 导师 V5 · 评估体系（评分表 / 前后测 / 校准）

> 配套主文档 `main.md`。目标：把"达标"变成**可测量、可复核、可比较**的分数。
> 版本：V5.8.1 · 状态：stable（版本锚点随主文档同步；模块版本见主文档 §12.1）。

---

## 1. 评估设计原则

1. **可观察**：只看作品与操作结果，不看"感觉"。
2. **分档锚点**：0–3 四档，每档有可描述的证据。
3. **权重显式**：每个标准有权重，总分可复算。
4. **关键项一票否决**：安全/正确性项为 0 则整体不通过。
5. **形成性优先**：60% 过程（作业/小测/里程碑），40% 结果（项目/作品集）。
6. **双人校准**：关键项目双评，差异 >1 分按锚点复核。
7. **前后测**：每模块开始/结束各一次，记录增量。

## 2. 入门诊断（前测）

### 2.1 问卷（8 问，0–1 分/问）
1. Blender 使用时长（<1 月 / 1–6 月 / >6 月）
2. 是否完成过完整项目（建模→UV→材质→渲染→输出）
3. 是否会用 Graph Editor 调整插值与手柄
4. 是否会用几何节点/模拟区
5. 是否会骨骼绑定与权重
6. 是否能独立定位崩/黑/穿透
7. 是否会写 `bpy` 脚本
8. 每周可投入时间（<5h / 5–15h / >15h）

### 2.2 实操小测（5 题，0–2 分/题，共 10 分）
1. 建 1m×1m×0.1m 板，Apply 缩放，原点居中（0–2）
2. 倒角 + SubD，说明支撑边位置（0–2）
3. 检查 manifold 并说明 N-gon 风险（0–2）
4. UV 展开并报告重叠/拉伸（0–2）
5. 渲 512×512 并说明色彩管理与采样（0–2）

### 2.3 级别判定
| 总分 | 判定 | 建议起点 |
|---|---|---|
| 0–3 | L0 | M0 |
| 4–6 | L1 | M0 后半 + M1 |
| 7–8 | L2 | M1 + 补弱项 |
| 9–10 | L3 候选 | M6 毕业项目 + 评审 |

## 6. 及格线与关键项

- **关键项分两级（判定不变：两级都必须 ≥2，任一为 0 整体不通过）**：
  - **A 级 · 产品正确性**
    1. 建模非流形=0（或书面例外）
    2. UV 无重叠
    3. 无丢失贴图/粉材质
    4. 物理穿透=0（或书面容差）
    5. 渲染规格（分辨率/帧率/编码）正确
    6. 脚本不污染/不误删
  - **B 级 · 过程与验收**
    7. **验收数据来自产物**（fcurve/几何/渲染采样；生成器常量自证 = 0 分）
    8. **交付含自评 + 修改清单 + 明确询问**（缺 = 交付不完整，见 §11）
    9. **人体/类人动画：生物力学合理性 ≥2**（BIO-001；无发力链/脚钉死受击/反关节任一 = 0 则整体不通过；非人体项目标 N/A 并说明、不参与一票否决；人体项目不可 N/A）
- **N/A 规则**：B 级项在非交付型任务（单次答疑）可在自评中标 N/A 并说明；A 级项任何场景不得 N/A。
- **通过条件**：加权均分 ≥2.0，关键项全部 ≥2；关键项任一 0 则整体不通过。
- **优秀**：加权均分 ≥2.5 且至少 3 项为 3 分。
- **等级映射**：均分 <1.5=L0/L1；1.5–2.0=L1/L2；2.0–2.5=L2/L3；≥2.5=L3/L4。

## 7. 评分表模板（CSV 可直接用）

```csv
项目,域,标准,权重,得分(0-3),加权分,备注
静物台,基础,变换与原点,0.4,,,
静物台,基础,单位与命名,0.3,,,
静物台,基础,场景管理,0.3,,,
...
```

**计算**：加权分 = Σ(标准权重 × 得分)；域归一权重 = 域权重 / Σ(该角色全部域权重)；项目分 = Σ(域归一权重 × 域内加权分)。总分保留两位小数（归一化后满分 100；§5 列和为 100 时归一化不改变数值）。

## 10. 校准与迭代

- 每次评分抽取 10% 作品做双评，记录差异；
- 差异集中在某标准 → 修订锚点描述；
- 每季度统计：通过率、分数分布、常见 0 分项 → 回写课程与误区库；
- 目标：同一作品两次评分差异 ≤0.5（加权）。

## 11. 交付后自评与修改清单（强制模板，V5.2.0 新增；V5.3.0 增补生物力学行）

> 对应主文档 `§2.8 交付闭环协议`。任何交付必须填完本模板才算完成；缺一项按关键项 #8 判 0。

### 11.1 自评表（对产物采样，不抄参数表）

| 项 | 证据（数值/文件/行号） | 结果 | rubric 分 |
|---|---|---|---|
| 交付规格（分辨率/帧率/编码/范围） | 如 movieclip 反查 60 帧/30fps/1080p | pass | — |
| 关键项 1–9 | 逐项给证据 | pass/fail | 0–3 |
| 域评分（如 §4.7 动画） | 曲线质量 / 可读性 / 循环 / 能量缩放 / **生物力学（人体动画）** | 加权 x.xx | 2 |
| 已知未修项 | 逐条列 | 不计分 | — |
| 已知边界/有意取舍 | 如原地循环、木偶分段 | 记录 | — |

**禁止**：
- 只列通过项、不列未修项；
- 用"看起来可以""应该没问题"代替数值；
- 用生成器常量/参数表/自己写的 spec 当验收证据（关键项 #7）；
- 只测整数帧、不测亚帧/60fps（红线 #38）。

### 11.2 修改清单（CSV 可直接用）

```csv
编号,优先级,问题,证据,修法,成本/风险,建议顺序
P0-1,,,,,,
P1-1,,,,,,
P2-1,,,,,,
```

- 优先级定义：**P0** 不改则交付不合格/有硬伤；**P1** 明显影响质量但可交付；**P2** 打磨/可延后；
- 每项必须能"改完再测"（有回归标准）；不写无法验证的条目；
- 至少 3 项、最多 8 项；每项给"改/不改的代价"。

### 11.3 询问模板（D4，必须用选项）

```text
下一步选一个：
A. 全改（P0+P1+P2，分轮执行）
B. 只改 P0（编号：…）
C. 只改指定项（报编号）
D. 不改，交付验收完成
E. 换方向（重新定义目标）
```

### 11.4 回归与再自评

- 用户选 A/B/C 后：修复 → **回归验证**（原断言 + 新增断言）→ 重出自评表 → 再问；
- 用户选 D/E 或未回复：交付封存，不再擅自修改；
- 每次修改必须同步更新变更记录（`CHANGELOG*`）与版本号（如 v1→v2）。
