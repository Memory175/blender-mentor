# ENG-001 · 工业设计与可制造性

> 通用模块 **ENG-001 v1.1.0**（本地试验版）
> - **版本**：v1.1.0
> 适用：产品/道具/硬表面模型的受力、制造、人体工学与装配审查。
> 不适用：需要真实 FEA 强度认证、模具流道/冷却分析、量产公差链计算的场景。

## 1. 何时加载

- 用户问“能不能注塑/铸造/3D 打印”“壁厚/拔模/悬垂/倒扣”；
- 用户要审查装配、螺丝/卡扣/胶水/一体化；
- 用户要检查重心、支撑面、应力集中、干涉、握持空间；
- 用户要交付“可制造版”而不是“渲染版”。

按 `load_router.py` 的 engineering 触发词加载；与 ESD/BIO 同时命中时，按任务主目标保留 2 个模块。

## 2. 力学

### 2.1 重心

- 重心投影落在支撑面内，且离边缘留 **≥10% 支撑宽度**；
- 装载/配重后重算；高瘦件、把手侧向受力要单独校核倾覆；
- Blender：单对象可用 `Origin to Center of Mass (Volume)`；装配体按体积加权求质心。

### 2.2 支撑面

- 取实际接地点（不是包围盒底面）在水平面的凸包；
- 接地点 ≥3 且不共线；软垫、圆角、脚垫会缩小有效支撑面；
- Blender：底部顶点投影 + 2D 凸包；侧向力工况看绕支撑边的力矩。

### 2.3 应力集中

- 内圆角 **r ≥ 0.5t**（t 为较薄件厚度），最好 ≈1t；
- 孔边到边缘 ≥2d；截面变化做渐变，避免 90° 台阶；
- 连接处（把手/耳/支架）是高应力区，必须圆角过渡；
- Blender 只做几何检查，强度结论需外部 FEA。

### 2.4 干涉与碰撞

- 不同零件不允许共享体积；固定配合留 0.1–0.3 mm 间隙；
- 运动件要做全行程扫掠，逐帧检测；
- Blender：Boolean Intersect 或 `mathutils.bvhtree.BVHTree.overlap()`；3D Print Toolbox 的 Intersect 可列相交对象。

## 3. 制造工艺

### 3.1 材料厚度

| 工艺 | 常用壁厚 |
|---|---|
| 注塑 ABS/PC | 1.5–3 mm（小件 1–2，大件 2.5–4） |
| 压铸铝 | 1.5–3 mm |
| 陶瓷日用 | 3–5 mm |
| FDM 3D 打印 | 0.8–1.2 mm（2–3 圈壁厚） |

- 厚薄变化尽量 < ±20%；加强筋取主壁厚 0.5–0.6；
- Blender：3D Print Toolbox Thickness；或从表面向内 raycast 采样。

### 3.2 拔模斜度

- 一般塑件 1–2°；深腔/纹理 2–3°；最小 0.5°；
- 拔模方向统一；倒扣需要滑块/斜顶/拼合模；
- Blender：面法线与 pull direction 夹角；脚本支持 `mold_sides`（如 +Z / -Z）分侧统计，
  输出每侧最小拔模与低拔模面积；单方向拉模时外壁/内腔符号相反，倒扣仅作候选提示。

#### 3.2.1 侧向抽芯 / 滑块 / 拼合模

`mold_sides` 只覆盖主开模方向。以下结构必须在 `side_actions` 里声明，并人工确认：

| 结构 | 典型方案 | Blender 检查 |
|---|---|---|
| 侧孔、侧凹 | 滑块 / 斜导柱 | 滑块作为独立集合，沿抽芯方向做扫掠干涉 |
| 内部倒扣 | 斜顶 / 内抽芯 | 检查顶出行程与干涉 |
| 闭合环把手/环扣 | 拼合模 / 可溶芯 / 分件粘接 | 拆模方向与分型线 |
| 内螺纹 | 可缩芯 / 旋转抽芯 | 旋出路径扫掠 |

脚本只在 `side_actions` 声明时打印 info，**不做几何自动验证**；未声明侧向倒扣仍可能漏检。

### 3.3 焊接过渡

- 焊趾平滑过渡，避免尖锐缺口；
- 角焊缝焊脚约 0.7–1.0×较薄板厚；
- Blender：用 Bevel/Fillet 模拟焊趾，剖面看过渡。

### 3.4 陶瓷烧制形变

- 收缩率常见 10–20%，建模要放收缩余量；
- 壁厚均匀、内角 ≥3 mm、避免大面积厚薄突变；
- 烧制支撑/垫片会影响最终形状；
- Blender：按收缩率缩放置模型做尺寸核对，剖面看壁厚变化。

### 3.5 3D 打印悬垂角

- FDM：与竖直方向夹角 >45° 的悬垂需支撑；
- 最小壁厚 0.8–1.2 mm；最小孔 1–2 mm；装配间隙 0.2–0.4 mm；
- 打印方向决定支撑量，优先把关键面朝上/避免大面积 downface；
- Blender：3D Print Toolbox Overhang；或按 `asin(-n·build_dir)` 统计向下面；
  脚本额外输出悬垂面积与**支撑体积估算**（面积 × 到台面高度，偏保守）。

## 4. 人体工学

### 4.1 握持空间

- 手指通过空间 ≥25–30 mm；握把直径 25–40 mm；
- 手掌宽度参考 80–95 mm；边缘圆角 ≥2–3 mm；
- Blender：手部参考模型/圆柱包络检查穿插；测内空尺寸。

### 4.2 受力点分布

- 接触面积越大、边缘越圆，压强越低；
- 避免小凸点/锐边集中载荷；提手/握把方向与主应力一致；
- Blender：接触区域渲染 + 简单载荷/面积估算。

### 4.3 操作可视性

- 操作件在正常视线/手势范围内，不被把手/盖沿遮挡；
- 戴手套操作要放大接触面与间距；
- Blender：用户视高相机渲染第一人称视图；运动件做扫掠。

## 5. 装配逻辑

| 连接 | 关键尺寸/规则 |
|---|---|
| 螺丝 | 塑料柱外径 ≈2×螺丝大径；通孔 +0.2–0.5 mm；柱根圆角；留批头空间 |
| 卡扣 | undercut 0.5–1 mm；应变 2–3%；根部圆角；拆装要工具口 |
| 胶水 | 胶层 0.05–0.2 mm；表面处理决定强度；热膨胀系数接近 |
| 一体化 | 能一体就一体；双色包胶要机械互锁；living hinge 用 PP，0.25–0.5 mm |

装配审查：

- 每个零件只出现一次，连接方式明确；
- 装配方向/工具空间/防错（poke-yoke）；
- Blender：爆炸图 + 插拔路径扫掠 + BVH 干涉。

## 6. Blender 检查清单

- 3D Print Toolbox：Thickness / Overhang / Intersect；
- MeasureIt：关键尺寸；
- `Origin to Center of Mass`：单件重心；
- BVHTree：静态/动态干涉；
- 第一人称相机：可视性；
- 脚本：`scripts/engineering_check.py` 输出稳定性/壁厚/拔模/悬垂/干涉的 JSON 报告；
  配置支持 `proxy_objects`（排除渲染代理）、`intentional_contacts`（允许座合/过盈配合）、
  `mold_sides`（+Z/-Z 分侧拔模）、`side_actions`（侧向机构声明）、`clearance_pairs`（指定配合对最小间隙）。
- 回归：`python scripts/engineering_regression.py --blender <blender>`；
  fixtures/configs/expected 在 `tests/engineering/`，用 `--update` 更新期望。

## 7. 验收口径

| 等级 | 含义 |
|---|---|
| pass | 所有硬规则达标，无 fail/warn |
| warn | 存在需要工艺确认的项（如倒扣、支撑、厚薄变化） |
| fail | 壁厚低于下限、拔模不足/倒扣无方案、干涉、重心出支撑面、悬垂超限 |

机器检查只作为**规则预检**，不能替代 FEA、模流分析和量产验证。

## 8. 常见错误

1. 把包围盒中心当重心；
2. 用底面当支撑面，忽略实际接地点；
3. 只给外观倒角，忘了内凹应力集中；
4. 用视觉贴合判断无干涉；
5. 壁厚只看最薄处，忽略圆角实际厚度；
6. 直壁不做拔模；倒扣不做滑块；
7. 陶瓷按最终尺寸建模，不放收缩；
8. 3D 打印按错误方向检查悬垂；
9. 只量把手长度，不量内空；
10. 装配连接方式没定义就交付 STL/STEP；
11. 侧向倒扣不声明滑块/斜顶，只检查主开模方向。
